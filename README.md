## 🛠️ How to Compile & Run

All solutions are written in standard Java. You can execute any of these files on your local machine using the command line:

1. **Navigate to the topic folder**:
   ```bash
   cd "topic-folder-name"
   ```
2. **Compile the java file**:
   ```bash
   javac FileName.java
   ```
3. **Execute the class file**:
   ```bash
   java FileName
   ```

*Note: For files in `TwoSumAprroachProblems/src`, compile using the root or direct path:*
```bash
javac TwoSumAprroachProblems/src/ContainerWithMostWater.java
java TwoSumAprroachProblems.src.ContainerWithMostWater
```
